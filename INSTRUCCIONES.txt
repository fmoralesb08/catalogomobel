1. En GitHub, abre cada archivo con el mismo nombre: config.js, app.js, catalogo.js y producto.js.
2. Pulsa el lápiz, borra todo y pega el contenido del archivo correspondiente de esta carpeta.
3. Haz Commit changes después de cada archivo.
4. Espera 1 a 3 minutos a que Cloudflare despliegue.
5. Abre catalogomobel.com y presiona Ctrl + F5.

Google Sheets debe estar publicado en la web y la pestaña Productos debe conservar estos encabezados:
SKU, Nombre, Precio, Categoría, Presentación, Imagen, Archivo imagen sugerido, Descripción, Destacado, Mostrar.

Para mostrar un producto en Inicio, escribe TRUE en Destacado.
Para ocultar un producto, escribe FALSE en Mostrar.
La columna Imagen debe contener el nombre exacto del archivo existente en /img/productos/.
